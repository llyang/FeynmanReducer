# Differential equations

This example generates the master-integral differential equations for the
two-loop outer-massive double box directly from its Lee--Pomeransky
polynomial. It also reduces the 22 original targets from `targets.txt` in the
same run, demonstrating that ordinary reductions and differential equations
share one final master basis.

The output contains one connection matrix for each free kinematic parameter
`msq`, `s`, and `t`. Matrix rows and columns follow the 29 masters written to
`outputs/final_basis.txt`.
